How to add it in Gmail

  1. Click Copy signature, or open the downloaded HTML file in a browser and click its copy button.
  2. In Gmail, click the gear icon → See all settings → General tab → Signature.
  3. Click Create new, name the signature and paste it (Ctrl/Cmd + V).
  4. Set it as the default for new emails and for replies.
  5. Scroll to the bottom of the page and click Save Changes.
